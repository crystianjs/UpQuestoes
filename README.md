## 💻 Sobre o Projeto

O **UPQUESTOES** é uma plataforma web de alta performance desenvolvida para otimizar os estudos e o acompanhamento de desempenho voltado para concursos públicos, com foco especial no edital de **Escrevente Técnico Judiciário do Tribunal de Justiça de São Paulo (TJSP)** sob os padrões da banca **VUNESP**.

O sistema conta com registro dinâmico de questões por disciplina oficial, cronômetro integrado para treinamento de redações dissertativas e um painel de controle analítico em tempo real.

---

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído utilizando as melhores práticas do ecossistema web moderno:

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Banco de Dados:** [Supabase](https://supabase.com/) (PostgreSQL hospedado)
* **Estilização:** Tailwind CSS
* **Controle de Versão:** Git & GitHub CLI

---

## ✨ Principais Funcionalidades

- **Registro de Questões por Matéria:** Lançamento diário de blocos de estudo com contagem de acertos, erros e apontamento de pontos de melhoria.
- **Painel de Desempenho Analítico:** Gráficos e indicadores consolidados com filtro dinâmico por disciplina do edital.
- **Treinador de Redação:** Módulo de redação cronometrado com contagem de palavras e salvamento automatizado em banco de dados.
- **Interface Dark Mode Exclusiva:** Design moderno focado em produtividade de alta imersão.
